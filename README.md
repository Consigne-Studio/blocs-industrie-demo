# UI-103 · Blocs Industrie & Énergie pour shadcn/ui : démonstration

Démonstration en ligne de **UI-103**, 31 blocs React et 3 écrans complets pour la supervision
industrielle et l'énergie (shadcn/ui, Tailwind 4, React 19) : KPI à seuils, alarmes ISA-18.2 avec
acquittement, TRS, flux d'énergie, carte de parc.

**Voir la démo :** https://consigne.github.io/blocs-industrie-demo/

Ce dépôt ne contient que le build statique de la démonstration. Les données sont entièrement
simulées dans le navigateur ; sites, équipements et équipes sont fictifs. Le code source, le
registre shadcn et la documentation sont vendus sur la page du produit :
https://gumroad.com/l/blocs-shadcn-industrie

*English:* live demo of UI-103, 31 React blocks and 3 full screens for industrial monitoring and
energy built on shadcn/ui. This repository only holds the static demo build; source code is sold on
the product page above.
